# Sharing component: state-family repair

The anonymous sharing comparison mapped A to Jakub, B to Seenry and C to Emil. The user preferred B but rejected its finish as incomplete. This is not an accepted benchmark win. All three original generation runs reached their time ceilings.

The supplied screenshots exposed an email-only identity printed twice and an unconstrained fallback `img` inside an avatar styled only for inline SVG. Inspection also found that a permission change rebuilt the entire list and restarted every row's entrance animation. General-access changes replaced their trigger and hid Copy link while access was restricted.

## Candidate change

- Finish guidance now treats named, email-only, long-content, missing-asset and changing-control states as one family.
- Controls guidance sizes the actual media element and separates read-only facts from editable actions. Copying a URL is independent of granting access.
- Motion guidance preserves unchanged nodes and limits entrance motion to entering content.
- `decision_check.cjs` adds opt-in `distinct-text` and `contained-media` rules. Existing `state-change` checks cover node replacement and transient movement.
- Overlapping component planning prose is condensed. No new default resource bundle, font list, palette ban or extra model call is required.

The content checks are mechanical. They cannot certify composition, optical balance or professional quality. Intentionally repeated content and overflow require different project rules.

## Experiment boundaries

`luna-sharing-repair-011` gives one independent GPT-5.6-Luna high context the preserved B source, the original factual brief, user feedback and frozen revised Seenry guidance. It receives a 12-minute ceiling and authors its own interface changes and browser checks. No host interface edits, MCP, image generation or stronger-model visual critique are supplied. The previous comparison remains untouched.

This is a feedback-assisted repair, not a fresh-generation trial or an instructions-only ablation. It changes guidance and supplies specific feedback together. A successful repair would justify a fresh transfer test, not a claim of consistent superiority.

The original fails content, row-continuity and access-trigger checks at 320, 390 and 1000 pixels. Host evidence is stored outside the active author directory. Each run retains prompts, skill hashes, original source, intermediate snapshots and usage when returned by the provider.

Package validation and 178 Python tests pass on macOS; browser regressions exercise content fallback and existing decision/state rules in Chromium. These checks do not establish physical-device, Windows or Linux behavior for this revision.
