# Evidence support update: 2.0.1-dev.6

Implemented 21 September 2026 as a development candidate. The stable release was not advanced.

## Observable workflow changes

| Situation | Previous review gate | New version 2 review |
| --- | --- | --- |
| Every criterion says pass, but the palette choice is uncertain | Eligible if otherwise clear | Not eligible; request a controlled comparison |
| Typography visibly fails and the reviewer has strong supporting evidence | Repair | Repair; strong support cannot increase quality |
| Transition was not inspected | Missing-evidence route when recorded | Explicit uninspected support requires unverified quality and a specific observation |
| Some criteria need repair, others need inspection | One aggregate repair route | Preserve each action; report resolve-checks |
| A new request receives an old-format answer | No support assessment | Reject silent downgrade when the version 2 request is present |

New anonymous requests use version 2 by default. Explicit version 1 remains available for historical work. Direct evaluations of legacy reports label `support_assessed: false`. No probability of acceptance, automatic taste score, extra model service or MCP dependency was introduced.

The author records the current job, attention hierarchy, expression by region, material purpose and stable anchor before styling. One selected study can teach attention, expression or comparison. Studies are sourced summaries plus original local examples, with explicit applicability limits. They are not accepted benchmark artifacts or brand templates.
