# Seenry website study

An original marketing showcase with working examples for composition, motion, assets, branding and deck research. The Held furniture site is included as a complete local study. The five interactive examples are authored teaching material, not an unassisted model benchmark or customer result.

## Run

From this directory, run `python3 -m http.server 8000 --bind 127.0.0.1`, then open `http://127.0.0.1:8000/`. All fonts, image assets and runtime modules are local. External links to installation, GitHub and optional MCP documentation remain optional navigation. No build step is needed.

## Try

- Change composition and toggle its layout guides.
- Start, pause, reset or change the duration of the real local focus timer.
- Change an image crop and focal point, then export the actual PNG.
- Choose a brand palette and download the corresponding Markdown guidelines.
- Navigate the sample slides with controls or left/right arrow keys.
- Copy the installation command or a skill-specific prompt.

## Validation and limits

The local build was inspected at desktop, 390px and 320px browser widths. Timer completion, palette/crop selection, keyboard deck navigation, live reduced motion, install/prompt copying, a 900×1200 PNG export and an actual guideline export were exercised. Text-spacing overrides were checked and removed. These are browser-emulated widths, not physical-device tests. Clipboard-denied recovery is implemented but was not provoked. No independent motion recording audit or fresh-model transfer benchmark was completed. Human aesthetic acceptance remains separate.

This source is a development example. Publishing it in the repository does not deploy or replace seenry.design.
