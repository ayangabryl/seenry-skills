# Seenry Skills website
React + Vite + Motion. Canonical domain: https://skill.seenry.design.

Run `npm ci`, `npm run dev`, `npm run build`. Publish with `npm run deploy` using an authorized Cloudflare account. No environment secrets are bundled into the client.

The home page shows real agent output: same-prompt pages built with and without Seenry, unedited demo runs, and one run's working files. Captures come from the benchmark runs listed in DESIGN.md and live in `public/work/`; the photographs inside them were generated by the agents. The /motion page hosts the interactive motion library.

Open Runde: https://github.com/lauridskern/open-runde, self-hosted with OFL license in public/fonts. Interface icons: lucide-react (ISC).
