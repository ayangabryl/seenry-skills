# Seenry Skills website
React + Vite + Motion. Canonical domain: https://skill.seenry.design.

Run `npm ci`, `npm run dev`, `npm run build`. Publish with `npm run deploy` using an authorized Cloudflare account. No environment secrets are bundled into the client.

All five canonical skills have authored demonstrations. Video is covered by assets + motion, not an invented sixth skill. The comparisons are illustrative, not controlled model evaluations. MCP footage is the public Kopp reference already published in Seenry; reconstruction is the existing author-assisted study. Its source fonts/icons are not verified exact matches.

Open Runde: https://github.com/lauridskern/open-runde, self-hosted with OFL license in public/fonts. Vector studies are original code-native artwork. Interface icons: lucide-react (ISC).
