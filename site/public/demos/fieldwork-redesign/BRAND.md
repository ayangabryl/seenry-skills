# Fieldwork demo identity — revision 1

Fictional architecture studio. The redesign preserves the original projects, service facts, filters and inquiry behavior. Original SVG studies are illustrative, not documentary built work.

The implementation owns values in `index.html`, under “Seenry-guided revision”. Open Runde uses the existing local licensed font files. White and gray organize the page; charcoal is the primary action. Artwork retains its original colors. No decorative eyebrows, section rules, outlined headline lettering or numbered service labels. This is a scoped project rule, not a rule for all architecture sites.

The opening pairs the service proposition with a direct inquiry action and brings the original architectural study into view. Project names and locations are readable together. Shared pills retain visible keyboard focus, hover and pressed feedback. Inquiry fields retain persistent labels, validation and demo-only completion. Reduced motion removes decorative transforms.

Changes to type, control shape or color belong in shared rules and must be checked in navigation, project filters and the inquiry dialog. Do not restyle one action independently. Keep the project illustrations and content provenance intact.
