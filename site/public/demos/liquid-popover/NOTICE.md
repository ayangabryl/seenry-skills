# Liquid popover reconstruction

An author-assisted Seenry study of Kopp’s liquid popover recording.

Reference: https://seenry.design/design/24ebbdf6910e69ca125cfae5350b4d01
Source video: https://cdn.seenry.design/designs/24ebbdf6910e69ca125cfae5350b4d01/video.mp4
Inspected dimensions: 1154 × 720. Encoded rate: 60 fps. Duration: 10.133333 seconds.
Source SHA-256: 541a03098fc827ea1b6088cdcf9e00ee230790566b0bcdbc6d603d1a0a56be1e

The source recording is referenced remotely, not redistributed with this demo. It belongs to its credited creator. This implementation was authored, measured, tested and refined with Seenry guidance; it is not an unassisted one-shot benchmark. The original source code was not available.

Source font identity and exact icon shapes are unverified. Arial is an approximation; local icons are from Lucide React 0.468.0 under the ISC license in icons/LICENSE. Motion is fitted from visible frames. The observed hover is one rounded traveling highlight, fitted separately from opening and closing. Row-to-row movement takes approximately 200 ms; fade on leaving the menu is a proposed 120 ms response. Keyboard controls, touch layout, fast reversals and reduced motion are proposed behaviors.

The opening and closing implementation derives from seenry-skills commit 7512607, evals/replication-20260922/demo. The 2026-09-22 hover refinement adds hover.mjs and the corresponding shared background layer; the archived baseline remains unchanged. Comparison documentation and evidence remain in that repository.
