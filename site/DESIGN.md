# Seenry Skills site

Audience: developers and designers who use coding agents. Job: in under a minute, see what installing Seenry changes about an agent's output, believe it, and copy the install command.

## October 2026 redesign

The previous page gave each skill a tabbed playground of authored demos under a lettering toy. Visitors could not tell what the agent does. The page is now a skill page in the convention set by emilkowal.ski/skill and jakub.kr/skills (inspected 2026-10-09): a narrow document, the install command first, one section per skill named like the command, and a demo of what that skill changes. Seenry's difference is that every demo is real agent output or a real artifact from a run, not an authored mini component.

Sequence:

1. Intro: "/skills", two sentences with the claim and the benchmark result, the install command with copy, GitHub and Seenry MCP.
2. /seenry: same prompt, same model (Codex Sol 6.1), without and with Seenry + MCP, side by side on desktop and one Without / With toggle on phones (habit tracker, notes app, bakery).
3. /benchmark: "Led 15 of 18 tasks", the README benchmark on a 0 to 10 axis with values at the bar ends, the head-to-head, cost and method in one note, and the install command again.
4. /examples: one large page you can scroll, chosen from a strip grouped by prompt (hotel; coffee, API and architecture each run twice; three Claude Sonnet sites). Lowfold Coffee shows home, shop and product. Open the full site zooms a viewer out of the frame with Desktop / Phone.
5. /inside-seenry: the core skill's own loop, each step labelled with its run. Lilim Architects: three explored first screens and the blind pick; the critic's round-7 instruction above the section before and after the fix. Casa Andorinha: the finished room section and the photo-check scores; the floor chooser beside the brand rules Seenry wrote into DESIGN.md.
6. /seenry-motion: a Lowfold Coffee cart line whose total uses the skill's number transition, Before / With seenry-motion.
7. /more-skills: seenry-review, seenry-assets, seenry-branding, seenry-apps, seenry-decks, seenry-video, each with what it actually outputs. They get demos when they have real runs to show.
8. /faq.

## Brand guidelines

- **Idea:** a skill page that proves each skill with its own real output, in the documentation form developers expect from skills.
- **Type:** Open Runde (OFL, self-hosted). 400 for reading, 500 for emphasis and labels, 600 for the page and section names; 700 only in the wordmark. Page name 28px, section names 18px with a grey slash and a hairline, leads 18px at 1.65, notes 16px; nothing readable under 15px. Prompts, commands and skill names in the system monospace.
- **Palette:** equal-channel neutrals only. Canvas `#fafafa`, panel `#f2f2f2`, surface `#ffffff`, text `#1c1c1c` / `#4d4d4d` / `#6b6b6b`, slash `#9a9a9a`, hairline 8% black. Colour comes only from the agents' output.
- **Layout:** a 720px reading column; evidence cards break out to 1040px. 128px between sections.
- **Radius:** demo cards 22px holding 16px stages at a 6px inset; captures 10 to 12px; install card 18px with 14px rows; toggles full pills; viewer 20px. Cards carry a 7% ring; only the viewer has a shadow.
- **Controls:** one pill toggle for every before/after, page and device switch; underline tabs only for choosing an example; a thumbnail strip with a 2px selected ring for the gallery.
- **Motion:** toggle pill and tab underline on a critically damped spring (stiffness 800, damping 56); before/after crossfade 160ms; copy icon out 70ms, check in 110ms after 30ms, label 100ms; viewer 220ms in, 120ms out; card captures zoom 1.5% on hover; the counter rolls changed digits in 420ms. Scroll the page travels at 320px/s and Pause freezes in place. Reduced motion removes all of it.
- **Owned detail:** the prompt, lowercase and unedited after a grey caret, above every piece of output.
- **Rules:** a demo is real output or a real run artifact, never an authored mock; every number carries its method nearby; no eyebrows, numbered steps or dots before text; a skill without real output gets a sentence, not a fake demo.

The /motion library page is unchanged and still uses `reading-site.css`, which the home page also loads for its base styles.
