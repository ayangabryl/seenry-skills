# Sound-library direction probe — 2026-09-29

This is development evidence for a narrow change to the direction-study reviewer. It is not user acceptance or a controlled superiority result.

A fresh builder using the installed Seenry skill made a working demo sound catalog with four original auditionable WAV files, license explanation, pack selection, and no autoplay. The two studies used the same facts. A placed all four playable samples beside license and pack information; B gave one selected cue a larger waveform and darker listening surface but delayed the licensing decision. The four unchanged study captures are in `captures/`.

The existing direction prompt returned **Keep A** in the builder's run and in one independent replay. The candidate prompt asked the reviewer to weigh both the task path and subject-specific material, and to consider a feasible synthesis when those strengths were split. It returned **Revise** in two independent runs, identifying the same repair: preserve A's sample/license adjacency while giving a selected cue more material presence, with less space spent on the general introduction. The four raw verdicts are in `reviews/`. The candidate prompt is the proposed change in this branch.

The builder continued from the original Keep A. Its first complete phone capture and repaired final phone capture are preserved. The final first-screen typography and whole-task gate and the full-page writing and whole-task gate all returned Keep. The gates found a wrapped count, missing decision-state captures, and small phone labels; interaction testing found a rapid audio-switching bug. The builder repaired these. The gate verdicts did not establish that the final creative direction meets the owner's visual standard. The final remains a useful but restrained catalog.

**Limits:** The builder inadvertently read retrospective evaluation guidance that named a similar sound-library probe, although it did not open prior trial artifacts. Treat this run as workflow evidence, not an uncontaminated transfer test. The prompt comparison reuses one pair of images, one brief and an image reviewer with normal model variance; it does not prove that the candidate prompt generalizes or improves user preference. No controlled cost comparison or human rating was recorded. The builder measured DOM edges at desktop and phone widths but did not integrate the bundled visual ruler overlay, so ruler compliance remains unverified.
