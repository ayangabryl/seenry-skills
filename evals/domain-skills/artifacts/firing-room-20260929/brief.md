# Firing Room

Build a responsive, working web interface for a community ceramics studio's kiln schedule. Staff need to see the next firing, five queued pieces, current kiln stage and temperature, and the expected finish time. They should be able to switch between Queue and Running, select a piece to see its owner, glaze and firing target, and hold or release that piece. Sample data may be fictional but must be internally consistent; keep all changes local in the browser.

The first screen should show the operational task and at least one actual piece at phone width. The studio asked to avoid a soft editorial or lifestyle treatment: no large serif headline, category label above a hero, glow, or generic gradient cards. It wants an original direction that feels like durable workshop instrumentation while remaining clear to new staff. Build with plain HTML, CSS and JavaScript. Include useful keyboard states, reduced motion, and a 320 px layout.

Research one or two relevant product UI or motion references through the connected Seenry MCP. Use them for relationships and behavior, not assets or a copied composition. Keep source notes in DESIGN.md.
