## Controlled repair and transfer limit

Companion implementation: seenry-web/public/demos/liquid-popover and testimonial-carousel. The old evals/replication-20260922 artifacts remain unchanged. The new website source contains exact reference URLs, hashes, asset provenance and limitations in each NOTICE.md. Source media and branded assets are not added to installable skill packets.

Shared guidance now requires current intent routing, component identity, complete visible-state inventory and measured moving layers. It still permits inspired work when requested. No source palette, typography or brand becomes a universal recipe. These samples were directly repaired by the authoring agent; they do not establish fresh one-shot model performance or justify promoting a general accuracy claim. A fresh reference and counterexample remain necessary before such a claim.
