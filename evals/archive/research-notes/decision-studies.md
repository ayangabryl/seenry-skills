# Select a relationship to study

Use one case for an unresolved choice, not every case for every design. These are original summaries of public work and authored teaching examples. They are not accepted benchmark outputs or permission to reuse a company's assets.

| Choice | Study |
| --- | --- |
| Competing navigation, icons or actions | [Attention](attention.md) |
| Brand expression versus dense reading | [Expression](expression.md) |
| Comparable alternatives and consistent emphasis | [Comparison](comparison.md) |

Set `decision_study` to `attention`, `expression` or `comparison` in the existing packet project JSON. The compiler supplies only that case and its local working example, with hashes. With `--decision`, it replaces the generic example. No MCP or network is needed. Render the example and state the applicable relationship and countercase in DESIGN.md before applying it. Missing files stop compilation; unviewed source is not inspected visual evidence.
