# Authorized 100-request experiment

User requested 100–200 or more Jev loops. This experiment uses 100 live typed-decision requests, not 100 independently rendered websites. New budget authorization: maximum 100 attempts and $0.50 estimated ceiling. Official pricing/model rechecked before execution: jev-1.13.0, $0.042 per million input tokens, output free, text only. Maximum-context reservations total $0.2752512. The prior 12-call pilot ledger is preserved.

Phase 1:20 authored routing cases × base/reordered/guided =60 requests. Expected routes frozen before calls; this is a development set, not a held-out test.
Phase 2:6 design dimensions ×5 visitor contexts =30 requests. No predeclared aesthetic winner; choices generate hypotheses.
Phase 3:10 requests compare rendered finalists using actual textual browser observations, with dependent state frozen after inspection. They cannot directly inspect screenshots. Inputs are hashed before each phase and results never overwritten.

Build and inspect three actual full-page alternatives on the same content and assets. Retain a bounded candidate based on task fit plus browser review, not majority vote. Preserve disagreements and all results. No same-quality claim follows from request count. At most two visual repairs and one direction reset. Human preference pending. No automatic API retries, no publishing, no shared aesthetic default promotion.

Phase 3 refinement before its calls:5 task-specific choices using rendered measurements,3 diagnostic probes of phase 1 disagreements with narrower definitions,1 bounded evidence enhancement and 1 disposition. The probes are post-hoc development evidence, never replacements for original failures.
