A complete candidate and preserved original are available in [the comparison viewer](../../examples/jev-visual-trial/compare.html). Serve the repository root over HTTP; embedded previews need same-origin local assets.

## Roles and cost

TypeSafe Jev 1.13.0 selected the canvas structure from three textual alternatives (0.96 choice probability). A second call selected prominent website evidence for the design tool, contact-first for emergency service and catalog-first for a returning store customer. These are textual decisions, not visual ratings. The main coding agent authored the page and performed browser review. No json-render runtime was added; the useful pattern is constrained selection among prepared alternatives.

Two calls: 1,659 input tokens, 195 output tokens; estimated cost $0.000069678. Including the preceding three-call pilot: estimated $0.000180852. These are runner estimates, not a billing reconciliation. No further paid calls were needed.

## Verification and repairs

Inspected the complete desktop/mobile page, including the footer. Source hero bottoms fit inside the embedded preview: desktop about 756/780 source pixels; mobile about 856/900. The outer hero capture includes all associated preview material beyond the first viewport.

No horizontal overflow at 390 or 320 CSS pixels. Images and local fonts loaded. Fixed words joining when line breaks were hidden and increased small specimen copy; stacked the narrowest specimen. Composition toggles update the layout, selected state and accessible status; switching back works with reduced motion enabled. Installation copies with truthful feedback; Escape closes the dialog and restores opener focus. The complete Held study is existing authored material, not a new Jev-generated website.

## Core skill changes

Added a portable preview-scope check and an illustrated study to Seenry's marketing-evidence guide. The core requires no API key. Retained the optional capped Jev adapter for maintenance experiments. The original marketing example is unchanged.

This is a self-reviewed assisted iteration, not a blinded A/B evaluation. Human preference remains pending; neither Jev probabilities nor this example establish parity with professional reference websites. Service and store countercases were textual only, not rendered transfer tests.
