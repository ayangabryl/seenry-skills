# Learn relationships, then make a different system

Use when an identity needs a distinct direction or unrelated briefs keep receiving the same treatment. The method works from supplied applications and local studies without MCP. Connected research adds inspectable breadth; it does not decide the design for you.

Describe what visitors need to recognize, understand and do. For each useful reference record **visible relationship → possible function → new application → where it fails**. Keep the possible function an inference unless the designer explains it. Preserve working navigation, readable controls and truthful content; novelty can reside in evidence, imagery, composition or the decisive interaction. Changing a font and accent alone is not a new organizing idea.

## Three inspected contrasts

Inspected through Seenry on 2026-09-12. The current four/five-star branding search returned no results; these wider-library selections have no claimed curator endorsement. Each imported collection contains one video and one still, not a complete standards manual. Source credits below are library metadata. The notes are original observations; reference media is not bundled for reuse.

**Cadmus — Lovework.** The still shows a series of outdoor panels: academic verbs alongside line-drawn figures, a portrait in a shaped frame, dark wine lettering and pale warm surfaces. Observation: language, illustration and photography share a physical sequence. Possible transfer: give distinct parts of a new offering related visual roles across several applications, rather than repeating one decorative hero. Countercase: borrowing the academic motifs for an unrelated utility would weaken its meaning. Only the still was inspected; no motion or exact font attribution is claimed. [Reference](https://seenry.design/#/design/ca0266da5775d462027809d002b39f7b) · [Source](https://www.rebrand.gallery/rebrand/cadmus).

**Sommerro — Bielke&Yang.** The still shows spaced metal capitals on a building facade. The video's opening shows tall orange display lettering on a wine ground; its ending shows a muted purple printed book on stone. Observation: type scale, color and material change by application. Possible transfer: connect an expressive opening to quieter useful surfaces through selected identity relationships, instead of giving every heading the same treatment. Countercase: the large display lettering would need a separate legibility study in dense controls. Only the opening and ending video frames were inspected; timing and intermediate transitions remain unreviewed. [Reference](https://seenry.design/#/design/224249ed57992305a72be13555088a60) · [Source](https://www.rebrand.gallery/rebrand/sommerro).

**British Basketball League — Designwerk.** The still pairs a compact, stacked white wordmark with a slanted geometric symbol on black. Observation: mass, silhouette and compression establish identity with very little material. Possible transfer: a deliberately composed mark and evidence can carry character without adding multiple UI ornaments. Countercase: dense uppercase identity lettering is not evidence that ordinary field labels should use it. Only the identity still was inspected; the full site and motion are unknown. [Reference](https://seenry.design/#/design/b033a7a596f5e2ea6930319095173a64) · [Source](https://www.rebrand.gallery/rebrand/bbl).

Test the resulting direction with actual content in an expressive moment and a dense or utilitarian one. Change the subject in the concept: identify which relationships lose meaning. If none do, strengthen the evidence or central idea. Shared usable components can remain shared; variation must help this brief. Verify ordinary-size pixels and behavior before claiming the transfer succeeded.
