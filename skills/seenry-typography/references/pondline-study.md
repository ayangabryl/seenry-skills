# Same facts, three typographic reading paths

This is an original fictional study, created for Seenry. It is a decision exercise, not a house style or layout template. All three directions present the same three water-quality observation records: station, date, temperature and review status. The contrast comes from what the reader is meant to do first.

| Direction | Desktop | Narrow | First decision | Type follows |
| --- | --- | --- | --- | --- |
| Directory | [1440 px](pondline/directory-1440.png) | [390 px](pondline/directory-390.png) | Find a station | Large station names are row anchors; compact tabular temperatures and statuses stay comparable. The phone keeps records as scannable rows rather than turning them into a headline stack. |
| Specimen | [1440 px](pondline/specimen-1440.png) | [390 px](pondline/specimen-390.png) | Inspect one observation | One temperature dominates because the selected reading is the task. Other stations stay secondary yet reachable. The narrow view retains the unit, date and state near the value. |
| Journal | [1440 px](pondline/journal-1440.png) | [390 px](pondline/journal-390.png) | Read observations in date order | Dates and sentence-like entries set a slower record-reading pace. The serif supports that prose; it has no decorative italic phrase, tracked eyebrow or gratuitous label tier. |

The Directory is more useful for comparing stations; the Specimen is more useful for checking one reading; the Journal is more useful for a dated narrative. None is universally best. Choose from the actual user task, then inspect the narrow reading path and working state. The Journal proves that a serif can be purposeful; the anti-default check is against an unearned stack of type effects, not against serif fonts themselves.

These are sample observations, not live measurements or safety assessments. The screenshots show only static states; they do not establish keyboard, focus, motion or assistive-technology behavior. Do not reuse the sample content or visual treatment as a default for another product.
