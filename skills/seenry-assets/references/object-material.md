# Material inside a working component

Start with the person's operation. A thumbnail identifies the selected object. An editor needs room for the actual manipulation. A comparison needs enough detail to judge the difference. A viewer can make the material itself the experience. Choose the job before the preview's size; a supplied portrait photograph does not require a full-height portrait panel.

If an asset is missing, search for the needed subject through available native tools or a public owner/provider source. Preserve the item page, rights evidence and preview. Use the asset studio manifest when useful. A temporary licensed image can test composition, but it is not a fabricated client project. Keep attribution where its terms require it; put engineering provenance outside the ordinary task UI when no visible credit is required.

Inspect the actual file at its intended size. Preserve aspect ratio unless a crop is part of the operation. Do not call an enlarged thumbnail high resolution or print-ready merely because the export has more pixels. If the supplied source is small, show it at an appropriate scale, acquire a permitted larger version, or record that limitation. Its color does not by itself establish the component's brand palette.

For an editor/exporter, share crop, orientation, color/filter and size state with the output pipeline. The preview should represent the actual result. A grayscale construction placeholder must not silently become a desaturated final preview while the downloaded image stays colored. Attach the original material at surface/build stages along with construction images, identifying their different roles.

Use established control icon data and the host's type system. Artwork and custom illustration are separate from functional iconography. Copy only needed runtime files with their licenses; use documented APIs instead of reading whole minified bundles into context. The component owns selection, recovery and truthful state; an image or animation helper does not supply those behaviors.
