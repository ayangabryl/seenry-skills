# Finish the sequence

For deck construction or refinement, give each slide one narrative job and verify it against the preceding and following slides. Preserve supplied facts. Missing evidence is a content decision, not an invitation to fabricate a chart.

Set persistent margins, type roles and data conventions, then vary composition when the argument changes. Test real headlines and actual charts at presentation size. Avoid making every slide the same title-and-card grid. Review the entire ordered contact sheet for pacing, then inspect individual rendered slides for clipping, legibility and alignment.

Where the delivery format supports motion, preserve an object or relationship across a transition only when it helps explain the next idea. Keep reading time under presenter control. Do not stagger every bullet or animate decoration by quota. PDF/static exports must preserve the same claims, ordering and evidence without animation. Test the actual target format, not just a browser approximation. Record unsupported transitions and font substitutions explicitly.
