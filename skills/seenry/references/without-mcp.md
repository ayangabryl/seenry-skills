# Design without the reference server

Seenry's design process runs locally. MCP supplies additional reference evidence; it is not a license check, required runtime or source of aesthetic rules. Do not lower the design ambition, skip prototypes or replace research with invented citations when a connection is absent.

## Select an available evidence route

| Available capability | Work to do | Evidence to record |
| --- | --- | --- |
| Connected Seenry MCP | Inspect relevant references, their actual screens and recordings using [research](research.md). | Exact item, capture scope, observation, rating/reason when supplied. |
| Ordinary browser, no MCP | Inspect supplied links or a small public shortlist for the task. Study the complete relevant sequence, not just a hero. Use primary documentation for APIs and technical rules. | URL, date, viewport, observed states; no invented Seenry rating. |
| Local files, no network | Inspect supplied screenshots, recordings, existing UI, fonts and assets. Load the relevant built-in guides below and build original alternatives locally. | File, actual observation or an explicitly authored hypothesis. A written example is not a captured reference. |
| No visual inspection capability | Continue the brief, layout proposals, semantic implementation and available functional checks. Preserve renders for an equipped reviewer. | Visual/motion review pending. Do not certify pixels you could not inspect. |

Availability can differ by operation: a browser can render local HTML without internet. Do not repeatedly retry an unavailable service. Never silently install an MCP, require a paid prompt pack, or turn a failed lookup into a fabricated research result. Respect an explicit offline/no-MCP mode even if a server happens to be configured.

## Built-in decision resources

Load [visual decisions](visual-decisions.md) for grouping, typography and enclosure; [color decisions](color-decisions.md) for palette roles and appearances; [HCI decisions](hci-decisions.md) for task/feedback/recovery; and [interaction review](interaction-review.md) for verification. These authored guides include their sources for optional further reading; following their local instructions does not require visiting each link. If a current technical fact needs verification and network access is absent, use the installed package's documentation or flag that fact as unverified.

For motion, load the installed **seenry-motion** craft and choreography guides. Basic CSS/WAAPI interactions can run without a downloaded library. Bundled icon swaps are available locally; GSAP, Lottie and other adapters need their actual runtime dependencies. Do not select an unavailable renderer as the central idea. Keep a useful ordinary path and verify the chosen enhancement.

For assets, use installed **seenry-assets**. Prefer supplied licensed files and existing project icon/font packages. If an unavailable provider mark is essential, request that asset; for nonessential iconography use a clear text control until a genuine asset is available. A neutral local font fallback is preferable to a broken external font URL. Original code illustration is available when it explains the subject; it is not a substitute for a real product photo or logo.

## Six local studies to turn principles into hypotheses

These are original teaching scenarios, not claims about inspected customer research or award-winning sites. Test the proposed treatment against the current brief. Use them to reason, not as six page templates.

| Task / difficulty | Relationship to prototype | State and observable check | Counterexample |
| --- | --- | --- | --- |
| Save reading material without losing place | One alignment anchor for title, progress and next action; content carries character, quiet neutral controls preserve scanning. | Save → actual confirmation → undo in the same reserved area; keyboard focus remains stable. | A children's discovery library may need imagery and stronger category color; quiet monochrome alone may obscure differences. |
| Compare account limits | Keep label, value, unit and reset time adjacent; aligned numeric roles help comparison more than separate decorative cards. | Unknown, loading and stale values remain distinct from zero; update numbers without shifting units. | A single-account compact widget need not become a dense table. |
| Explore a studio's distinctive work | Derive navigation from a meaningful property of the work, such as scale, material or sequence; compare that mechanism with a direct project index. | Reversal returns to the same work; touch/keyboard can reach every project without hover. | A time-sensitive purchasing task may benefit from a conventional index instead of exploration. |
| Recover an interrupted upload | Put file identity, specific failure and retry together; reserve error color for actionable failures and keep successes quiet. | Retry preserves previous valid files; cancellation beats late async completion. | A promotional story has no need for upload-style status scaffolding. |
| Choose a creative collection | Let artwork supply varied color while controls share stable roles. Compare against a purposeful large brand-color field on the same content. | Selected item has a visible label/shape change, not hue alone; crop and label survive narrow width. | Color-coded analytical categories need separately distinguishable marks and a legend, not arbitrary artwork colors. |
| Scroll through a product mechanism | Sketch stages and reading holds first; link progress to the explanation with stable anchors and a direct summary. | Reverse, fast scroll, resize and reduced motion leave the explanation legible; no mandatory scroll game. | A simple form needs immediate access rather than a pinned introduction. |

Choose a relevant study or invent a better hypothesis for the task. Then follow the same workflow: three concepts, real wireframes, actual type, controlled surfaces and interaction proof, comparison, complete states, review. Record why the selected design serves this content. No reference subscription is necessary for this process; visual acceptance still requires inspecting the result.
