# Attention follows the task

**Apply when:** a dense interface gives navigation, metadata and the current action similar prominence. Identify what the person is doing now. Keep orientation recognizable while reducing competing emphasis; preserve target sizes and keyboard focus when reducing visible icon size.

**Working example:** [Attention comparison](../../assets/craft/attention.html) keeps the same content and geometry while changing navigation prominence. Switch workspace and directory tasks: navigation needs different emphasis in each. This original schematic demonstrates a choice, not a reference-quality interface.

**Countercase:** a first-time directory visitor needs to notice destinations. Dimming everything except one guessed action can make discovery harder.

**Check:** compare at actual size, then narrow width. Name which element wins attention and whether that matches the task. Verify controls remain discoverable, operable and visibly focused. Record one remaining weakness; removing borders alone is not success.
