# Attention follows the task

**Observed and declared source:** [Linear's March 2026 refresh](https://linear.app/now/behind-the-latest-design-refresh) reduces competing navigation, icon treatments and separators. Its sidebar comparison shows quieter inactive text, smaller icons and revised spacing. The team describes comparing changes inside the running product. Studied 21 September 2026; this does not establish user-outcome metrics.

**Apply when:** a dense interface gives navigation, metadata and the current action similar prominence. Identify what the person is doing now. Keep orientation recognizable while reducing competing emphasis; preserve target sizes and keyboard focus when reducing visible icon size.

**Working example:** [Attention comparison](../../assets/craft/attention.html) keeps the same content and geometry while changing navigation prominence. Switch workspace and directory tasks: navigation needs different emphasis in each. This original schematic demonstrates a choice, not Linear's interface or reference-level finish.

**Countercase:** a first-time directory visitor needs to notice destinations. Dimming everything except one guessed action can make discovery harder.

**Check:** compare at actual size, then narrow width. Name which element wins attention and whether that matches the task. Verify controls remain discoverable, operable and visibly focused. Record one remaining weakness; removing borders alone is not success.
