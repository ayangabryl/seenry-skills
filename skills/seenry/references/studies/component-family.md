# One system, different objects

Use when every component inherits the same title, box and action row despite serving different tasks. Decide which object carries meaning before selecting its visual treatment.

| Object | Relationship to explore | Countercase |
| --- | --- | --- |
| Music | Track identity near transport; progress and volume keep separate anchors | Large cover art can crowd controls in a compact host |
| Journey | Comparable endpoints share an axis; intermediate steps remain explicit | A direct-route diagram misrepresents a multi-stop journey |
| Forecast | Current answer leads, repeated future values support comparison | Atmospheric imagery must not obscure small values |
| Messages | Sender, excerpt and time form a row; unread state adds distinct information | A repeated decorative activity dot adds no information |
| Timer | Remaining time is the subject; start/pause remain in a fixed location | A decorative ring adds little to an unrelated numeric field |
| Notes | Document text can have a different voice from the controls | Dense numeric tools may need consistent compact typography |
| Collection | Real material establishes identity; metadata supports inspection | Arbitrary stock does not prove the product's actual content |

Change the useful relationship in alternative sketches: direct manipulation, simultaneous comparison or a stable object with disclosed detail. Keep a familiar form when it serves the task. Do not invent a gesture just to look different.

## When clean still looks unfinished

Check object hierarchy, surface meaning and choice rhythm. A normal booking does not need warning-like emphasis. Group its date, time and service as one identity; reserve notices for conditions requiring attention. Align comparable choices and keep the current value recognizable through review, confirmation and recovery.

Use content-specific type specimens and actual states to refine density, optical alignment and action emphasis. A tidy grid does not establish a good composition. Compare a representative finished state with a relevant inspected reference before claiming its finish is resolved.

For a selection change, animate the changing object inside stable labels and geometry. Single choices and ranges communicate different operations. Check interruption, reversal and reduced motion in the running result. No fixed palette, universal radius or approved component skin follows from these exercises.
