# One family, different objects

Use this study when alternatives merely move the same form above or below its result, or when an anti-slop review starts treating every dot, tint or pill as a defect. It is an inspected reference, not an output template or a human acceptance score for Seenry.

## Visible relationships

| Object and interval | Observation | Transfer question and countercase |
| --- | --- | --- |
| Music, overview at 1s | Cover and track identity sit together; transport controls and the seek/time region have separate, compact positions. | What identifies the current object, and what changes it? Cover prominence can help recognition; it should not crowd transport in a constrained player. |
| Flight, overview at 1s | Airport codes anchor the two ends; a connecting line/plane and paired times express a route. | Can comparable endpoints share an axis? A simple route treatment becomes misleading for a multi-stop itinerary or uncertain arrival. |
| Weather, overview at 1s | The current temperature leads; a repeated forecast row supports comparison on a colored field. | Which value is the immediate answer, and which values support it? An atmospheric field must still keep small forecast labels readable. |
| News, overview at 1s | Thumbnail/text rows repeat without prominent separators between every row. | Do image edges, alignment and proximity already establish grouping? Denser tables or ambiguous row boundaries can need separators. |
| Inbox, enlarged at 10s | Sender, message excerpt and time establish each row. Small unread dots and attachment thumbnails carry specific state/material information. | Is a marker communicating otherwise missing state? Unread is useful information; adding the same dot beside a redundant activity label is a different decision. |
| Focus timer, 15–20s | A large countdown occupies a tick ring on a dark blue field. Reset is compact; Pause has a larger contained target. | Quick note, overview at 1s | The note itself uses serif text; surrounding interface copy remains distinct. Different windows can make related material legible; they fail when arbitrary stock is used to imply work the product does not contain. |

## Apply the observation

Before choosing a palette, identify the information-bearing object and the person's next decision. Compare alternatives that change that useful relationship: simultaneous comparison, direct manipulation, or a stable object with disclosed detail. If the same familiar form is the clearest answer, retain it and describe the limited exploration honestly; inventing a gesture solely to appear creative can make the task worse.

The family is coherent without giving every object the same internal structure or surface color. That is an inference from the visible collection, not knowledge of the author's intent. Test it on the current brief with actual material and required states. The recording does not establish keyboard behavior, mobile reflow, error recovery, performance or production readiness. Verify those in the implementation.
