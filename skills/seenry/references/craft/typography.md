# Typography: test actual words

Use when hierarchy, line breaks, numbers or the font choice remains unresolved. Keep established brand families unless changing identity is in scope. A family name alone never establishes quality.

## Execute

Select a short shortlist based on audience, languages, content density and available font files. Render the actual heading, longest label, paragraph, prices and punctuation. Compare at similar perceived size, adjusting CSS size per family when necessary; equal numeric sizes are only a starting point. Verify supplied weights, italic availability, glyph coverage and optical-size support before requesting them.

Begin with clear title, body and supporting roles. Add a role only for a different job. Resolve hierarchy through position and weight before multiplying fonts, uppercase treatments or oversized headings. Uppercase remains appropriate for real abbreviations and some identities; field labels do not require it automatically.

Use tabular numerals where changing values should retain width, not for every word. Test real changes through the longest value. Set readable line lengths and line height using the actual script. Avoid hard-coded line breaks that destroy narrow composition. Preserve intentional editorial breaks only with responsive alternatives.

## Counterexample

A distinctive display face may serve a short exhibition title yet obscure departure times or multilingual error messages. A compact utilitarian face may be readable but miss an expressive brand's voice.

## Verify

Inspect narrow wrapping, 200% zoom, fallback rendering and the actual downloaded font files in production. Exercise long translated labels. Apply text-spacing overrides as tolerance tests, not mandatory default settings. Record available weights and the observation that selected the family. Never report a glyph or feature as verified merely because a related font supports it.
