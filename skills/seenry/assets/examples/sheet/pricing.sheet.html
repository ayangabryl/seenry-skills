Pricing section

A calm, tool-like pricing section where the price is the loudest thing on each plan and the recommended plan is obvious without shouting.

Why this design

Each decision, the reason for it, and the evidence behind it.

Tier container

One container divided by hairlines, not three floating cards

Plans read as one comparison. Separate shadowed cards compete with each other and misalign when copy lengths differ.

Evidence: Vercel and Linear pricing pages, inspected through Seenry MCP

Row alignment

CSS subgrid for plan, price, description, button and features

Buttons and feature lists line up across plans whatever the description length, which the leaders do by hand and we get for free.

Emphasis

Only the recommended plan's button is filled; a small badge names it

One primary action per view. Scaling or tinting the whole card is the common AI tell.

Price type

40px, weight 500, tabular figures, −0.02em

The price is the answer people came for. Light-to-medium weight and tight tracking match the measured leaders (Vercel 40/500, Stripe display weight 300).

Evidence: benchmarks.md

Inheritance

“Everything in Hobby, plus:” before each feature list

Shows only what changes between plans, so lists stay short and comparable.

Real products studied before designing, and what each one taught.

Guidelines

Rules for keeping future work consistent with this design.

Layout

Plans share one container divided by hairlines. Never float plans as separate shadowed cards.

DoOne container, 1px dividers, rows aligned with subgrid

Don’tThree cards with drop shadows and a scaled-up middle card

Color

Only the recommended plan gets the filled accent button. Everything else stays neutral.

DoOne filled button, others outlined

Don’tA filled button on every plan, or a tinted card background

Type

The price is the largest thing in a plan: 40px, weight 500, tabular figures.

Do$16 / seat / month with the period in secondary text

Don’tBold 700 prices, or a plan name larger than its price

Content

Each paid plan lists only what it adds, introduced by “Everything in X, plus:”.

DoFour short additions per plan

Don’tRepeating every feature from the plan below

Icons

Check icons align by their ink to the text edge, one icon set, 16px, accent-text color.

DoLucide check pulled 2.7px left

Don’tMixed icon sets, or icons boxed and indented
