# Reference notes

Research used the Seenry MCP (`search_sections`, `search_designs`, `get_reference_asset`, and `get_page_motion`). The linked published images were visually inspected. Static images establish layout and visual hierarchy, not interaction timing or keyboard behavior; motion in this kit is an authored, locally verified treatment. No reference media is bundled in the deliverable.

## Direction

Cool product neutrals, one blue action color, system sans type, a 6/8/12 radius family, and fine rules. The owned detail is an authored product state that stays meaningful when motion stops. Screenshots of the kit were inspected at 1440 and 390 pixels after the review board reached zero blockers.
