Foundations

Color

Cool greys split by hairlines. Ink blue is the one color that means act or selected. Status colors carry money meaning: red is overdue, failed or destructive; green is paid or settled; amber is disputed or at risk; slate is informational.

Actions and inputs

Button .ui-button

One filled primary per view. Secondary is the default; ghost for toolbars; danger is outlined red text and fills only inside the confirming dialog.

Text field .ui-field .ui-input

Always a visible label. Errors say what to do and sit under the field; affixes carry units.

Select and combobox .ui-select .ui-combobox

Native select for short fixed lists. Combobox wraps an input with a datalist when people type to find a customer or vendor among many.

Checkbox and radio .ui-choice

Checked controls fill ink blue, the same color as selection everywhere else.

Switch .ui-switch

For settings that apply immediately. In settings rows the label lives in the row and the switch keeps an accessible name.

Slider .ui-slider

A range input with its value written beside it. Use it for tolerances and thresholds where the exact number is shown; type the number when it must be exact to the cent.

Selection and navigation

Segmented control .ui-segmented

Switches a view, never submits. Selected is a raised white segment, not ink blue, so it never competes with the primary.

Tabs .ui-tabs

Sibling panels of one record or page. The 2px ink rule marks the selected tab.

Status and badge .ui-status .ui-badge

Status always pairs a word with a mark. A badge is a category, not a state.

Progress and meter .ui-progress .ui-meter

Progress is work moving; meter is usage against a limit and turns amber near it and red past it. The number is always written beside the bar.

Toast .ui-toast

A short result after an action, bottom right, never for errors that need fixing.

Skeleton .ui-skeleton

Matches the rows that will load; the shimmer stops for reduced motion.

Menu and tooltip .ui-menu .ui-tooltip

Floating layers are the only things with a shadow. Destructive items sit last, after a rule, in red.

Dialog and sheet .ui-dialog .ui-sheet

A dialog confirms one consequential act and names what will happen. A sheet holds a related task with more room.

Content and patterns

Card, avatar, accordion .ui-card .ui-avatar .ui-accordion

Cards are hairline frames, never shadows. Link cards darken their border on hover.

When does a reminder stop?
After four overdue reminders, when a promise to pay is logged, or when the balance reaches $0.00.
Who can void an invoice?
Controllers and admins. Every void is logged with its reason.

A description column beside bordered rows. Destructive actions live last, outlined red, and confirm in a dialog.
