Graphite components

Every seenry-ui and contract class in Graphite, in each of its states. Hover and focus are pinned with data-state so they read side by side; everything is live too. Copy markup from the source, without the gx- gallery wrappers.

Foundations

The values every component reads from tokens.css.

Color

Three surface greys and a hairline do all the structure. Hue is reserved for status marks, the failure series and app logos.

--bg --surface --surface-2 --hover --line --text --text-2 --text-3 --ok --warn --bad --info --idle

  • Page--bg
  • Card--surface
  • Selected--surface-2
  • Hover--hover
  • Line, strong--line-strong
  • Names and values--text
  • Secondary--text-2
  • Meta and icons--text-3
  • Primary fill--accent, the text color
  • Healthy--ok
  • Needs review--warn
  • Failing--bad
  • Informational--info
  • Idle or scheduled--idle
  • Series 1--chart-1, neutral
  • Failure--chart-2
  • Series 3--chart-3
  • Series 4--chart-4
  • Gridline--chart-grid

Inputs

Fields, choices and controls that take a value.

Input

A visible label above, help or error below in the small size. Errors turn the border and message red; nothing else changes.

.ui-field .ui-label .ui-input .ui-help .ui-error data-invalid .ui-control .ui-affix .ui-addon

Textarea

Multi-line input with the same border, focus and error rules as the field.

.ui-textarea

Select and combobox

Native select for short fixed lists; the combobox suggests from a datalist and still accepts anything typed.

.ui-select .ui-combobox <input list> + <datalist>

Checkbox, radio and switch

Checkbox for independent choices, radio for one of several, switch for a setting that applies at once.

.ui-choice .ui-radio-group .ui-switch role="switch"

Slider

A 4px track filled to the value with the number beside it. Use for a bounded amount where the position means something.

.ui-slider <input type="range"> + <output> --pct
